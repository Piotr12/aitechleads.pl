**Date:** 2026-10-18

## Goal

Two more hidden guides that **disregard the RACI chart** and tell our own story of how the open-mercato skills work
together, built from the skills repo alone. Spend real effort on review and self-critique to get the best
onboarding possible, then push to `main`.

## Plan

1. A shared brief from the repo only (`/tmp/atl-docs67/BRIEF.md`; the task tmp dir was cleaned twice, so this
   time it lives in the system tmp). It carries the house rules learned so far (no-prefetch links, mobile traps,
   noindex) and a CDP script for desktop/mobile screenshots and overflow checks.
2. Two builders, each in **its own git worktree** (Agent `isolation: worktree`), so each can build, serve on its
   own port (3461 / 3462) and look at its own pages. Earlier rounds couldn't do this because builders shared one
   worktree. Two different angles:
   - `/docs6` "Follow the work": the change itself as the protagonist; skills hand it on through artefacts,
     labels and chain markers.
   - `/docs7` "The first month": a team adopts the skills over time (setup, first ticket by hand, the autonomy
     dial, guardrails, retro and upgrade); the picture grows chapter by chapter.
3. A mandatory process inside each builder: model notes, then 2–3 concepts critiqued against a "newcomer test",
   then build, then at least two render-and-critique rounds (10+ logged problems each), then an accuracy pass
   against the SKILL.md files.
4. Then an **independent first-time-reader review** of each guide by a fresh agent, with its findings sent back to
   the builder for another revision.
5. Verify myself, merge both branches, then lint, typecheck, build, robots/noindex, a mobile sweep and a request
   count; push to `main` and check the live site.
